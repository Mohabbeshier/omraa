# دليل التشغيل

## ١. الاستخدام اليومي
دليل الموظفين جوّه النظام نفسه: `/omraa/guide.html`. فيه البيع، والمرتجع، والاستلام، والجرد، وطباعة الملصقات.

## ٢. المستخدمين والصلاحيات
- **الأدوار:** `owner` (مالك) بيشوف كل حاجة: التكاليف، والأرباح، والإعدادات، والنسخ الاحتياطي، وتجاوز مهلة الإرجاع. `employee` (موظف) بيبيع، ويرجّع خلال المهلة، ويشوف المخزون من غير أرقام تكلفة.
- **إضافة موظف أو تغيير كلمة سر:** من صفحة «المستخدمون» ← «إضافة موظف» (`/omraa/staff.html`)، للمالك بس.
- **إيقاف موظف:** من صفحة «المستخدمون» ← تعطيل. حسابه بيتقفل فورًا وسجلّه بيفضل محفوظ.
- **قاعدة:** لكل شخص حسابه. ماتديش حساب المالك لموظف.

## ٣. النسخ الاحتياطي والاسترجاع
| النوع | بيحصل إزاي | فين |
|---|---|---|
| نسخة يومية كاملة | تلقائي ٢ صباحًا UTC (`alomraa_daily_dr`) | جوّه قاعدة البيانات (`pos_backup`) |
| سجل تغييرات لحظي | تلقائي مع كل تعديل (`pos_backup.change_log`) | جوّه قاعدة البيانات |
| نسخة يدوية | صفحة «النسخ الاحتياطي» ← «أخذ نسخة الآن» | جوّه قاعدة البيانات |
| **نسخة خارجية** | صفحة «النسخ الاحتياطي» ← «تنزيل نسخة خارجية» | **ملف على جهازك، احفظه في درايف أو إيميل** |

- **الاسترجاع:** صفحة «النسخ الاحتياطي» ← اختار النسخة ← «استرجاع». النظام بياخد نسخة أمان أوتوماتيك قبل الاسترجاع، فتقدر ترجع لو غلطت.
- **مهم:** النسخ اللي جوّه قاعدة البيانات مش بتحمي لو الحساب نفسه اتقفل أو اتمسح. **النسخة الخارجية مرة في الشهر على الأقل إلزامية**، والنظام بيفكّرك لو اتأخرت.
- **قبل أي تعديل كبير** على البيانات أو الدوال: «أخذ نسخة الآن» الأول.

## ٤. المتابعة
| المتابعة | فين |
|---|---|
| كل خطأ بيحصل في أي جهاز | جدول `pos.omraa_error_log` (الوقت، والصفحة، والجهاز، والرسالة، وعدد المرات) |
| انقطاعات النت في المحل | جدول `pos.net_outages` |
| سلامة البيانات (مخزون، مرتجعات، شحن) | دالة `pos_fn_integrity_check()`، وتنبيهاتها بتظهر للمالك في الرئيسية |
| صحة النسخ الاحتياطي | `pos_fn_backup_health()`، وصفحة «النسخ الاحتياطي» |
| الموقع الحي | GitHub Action يومي (`.github/workflows/daily-site-audit.yml`)، ولو فشل بيوصل إيميل لصاحب الحساب |

## ٥. الأجهزة
- **المتصفح:** Chrome أو Edge محدّث.
- **ساعة الجهاز:** على «ضبط الوقت تلقائيًا» و«المنطقة الزمنية تلقائيًا». النظام بيصحّح فرق الساعة لوحده، بس الضبط الصح بيمنع أي لخبطة.
- **قارئ الباركود:** USB بوضع لوحة مفاتيح. لو حاسس إنه بطيء، افتح `/omraa/diagnose.html`.
- **على الموبايل:** «إضافة للشاشة الرئيسية» بيخلّيه يفتح زي التطبيق.

## ٦. التحديثات
- **مصدر التحديث:** أي تعديل بيتنشر من ريبو `omraa` (فرع `main`).
- **وصول التحديث للأجهزة:** الأجهزة بتجيب التحديث لوحدها، ولو الصفحة مفتوحة بيظهر شريط «فيه نسخة جديدة».
- **قبل النشر:** `bash scripts/check_before_push.sh` إلزامي قبل أي `git push`.
