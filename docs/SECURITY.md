# الأمان

## اللي اتعمل
- **مفيش جدول مفتوح للمتصفح.** كل حاجة بتمر بدوال `pos_fn_*` و`shop_fn_*`، وكل دالة حساسة بتتحقق جوّاها من:
  - إن المستخدم موظف فعّال (`pos.assert_staff()`).
  - أو إنه مالك (`pos.is_owner()` / `pos.current_app_role()`).
- **المتجر (زائر من غير دخول):** بيقدر يقرا الكتالوج، ويعمل طلب، ويكتب تقييم، ويسجّل أحداث التصفح، بس. مفيش وصول لأي بيانات عملاء أو مبيعات أو تكاليف.
- **إنشاء الحسابات:** مفيش إنشاء ملف موظف تلقائي عند التسجيل. الموظف بيضيفه المالك بس.
- **التكاليف والأرباح** مش بتظهر للموظف، لا في الواجهة ولا في الدوال.
- **المرتجع والإلغاء** بيتحققوا من نفسهم: القطعة رجعت المخزون، والفاتورة اتعلّمت، والحركة اتسجّلت.
- **النسخ الاحتياطي:** نسخة يومية + سجل تغييرات لحظي + نسخة خارجية يدوية.
- **مفيش أي مفتاح سري في كود الموقع.** المفتاح الموجود هو مفتاح anon العام، ودي طبيعته.

## على المالك
1. **إعدادات Supabase** (مرة واحدة):
   - Authentication ← Sign In / Providers ← Email ← **Allow new users to sign up = Off**.
   - Authentication ← **Leaked password protection = On**.
   - **فعّل 2FA** على حساب Supabase وحساب GitHub.
2. **كلمات السر:** كلمة سر قوية ومختلفة لكل حساب. ماتتبعتش في شات، ولو اتبعتت غيّرها فورًا.
3. **الموظفين:** لكل موظف حساب خاص بيه، والموظف اللي يمشي يتعطّل حسابه في نفس اليوم.
4. **السورس:** مايتديش لحد غير مطوّر وقّع «تعهد المطوّر» (ملحق التعهد).
