## في دقيقة
- **نقطة البيع والإدارة:** صفحات ثابتة على GitHub Pages (`/omraa/`)، بتكلّم قاعدة بيانات Supabase مباشرة.
- **المتجر الإلكتروني:** موقع Next.js ثابت (`omraa-store-src` → `omraa-store-preview`)، بيكلّم نفس قاعدة البيانات بدوال عامة محدودة.
- **قاعدة البيانات:** Supabase (PostgreSQL). كل العمليات بتمر من دوال (`pos_fn_*` / `shop_fn_*`) بتتحقق من الصلاحية جوّاها، والجداول مقفولة بـ RLS.
- **التكلفة:** صفر جنيه. كله على الخطط المجانية، وعشان كده فيه حدود لازم تتراعى (OPERATIONS §٧).
- **الترخيص:** كل تركيبة فيها `license.json` موقّع من المالك. من غيره بيظهر شريط «نسخة غير مرخّصة».
