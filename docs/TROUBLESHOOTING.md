# حل المشاكل

ابدأ دايمًا بالسؤالين دول:
1. **النت شغال؟** النقطة الخضرا/الحمرا تحت الشاشة بتقول «متصل» أو «مفيش نت».
2. **الصفحة محدّثة؟** لو فيه شريط «فيه نسخة جديدة»، دوس «حدّث دلوقتي».

| المشكلة | السبب الغالب | الحل |
|---|---|---|
| «انتهت الجلسة — اضغط هنا لتسجيل الدخول» | الجلسة فعلًا انتهت (باسورد اتغيّر، أو الحساب اتعطّل، أو بقالك أيام من غير دخول) | دوس على الشريط وادخل تاني. الشريط بيستنى ١٢ ثانية ولو الجلسة رجعت مابيظهرش، فلو ظهر يبقى لازم دخول |
| السيستم بيدخل ثانية ويخرج لوحده | ساعة الجهاز غلط جدًا، أو الكوكيز ممسوحة | اضبط الساعة على «تلقائي». النظام بيصحّح فرق الساعة بس الضبط أحسن. لو مستمرة: امسح بيانات الموقع وادخل تاني |
| الباركود بطيء أو مش بيقرأ | النت ضعيف، أو القارئ مش على وضع لوحة المفاتيح | افتح `diagnose.html` وجرّب. لو «timeout» كتير يبقى النت. النظام بيعيد المحاولة لوحده |
| «بطء في الاتصال — لم يتم التنفيذ، جرب تاني» | النت قطع أثناء العملية | جرّب تاني. البيع عنده حماية من التكرار، فالضغط مرتين مايعملش فاتورتين |
| المرتجع بيقول «انتهت مهلة الإرجاع» | الفاتورة عدّى عليها أكتر من المهلة (١٥ يوم افتراضيًا) | لازم حساب المالك، وتعليم «أنا موافق أتجاوز المهلة» |
| «لا توجد قطعة مباعة بهذا الباركود قابلة للإرجاع» | القطع دي اترجعت قبل كده، أو اتباعت من موديل/مقاس/لون تاني | دوّر برقم الفاتورة أو موبايل العميلة بدل الباركود. الشاشة بتقول السبب |
| فاتورة اتعملت غلط | — | في أول ٣٠ دقيقة: المرتجعات ← دوّر برقم الفاتورة ← «إلغاء الفاتورة كلها». بعدها: مرتجع عادي |
| الشحنة مش بتتسجّل | رقم الموبايل ناقص أو غلط، أو مفيش عنوان | الرسالة بتقول السبب. الأرقام العربي بتتقبل عادي |
| «الـSKU مستخدم لموديل تاني» | الرقم ده متاخد | الرسالة بتقترح رقم بديل |
| صورة مش بتترفع | الصيغة HEIC (آيفون) | حوّلها JPG، أو من إعدادات الكاميرا اختار «الأكثر توافقًا» |
| شريط أحمر «نسخة غير مرخّصة» | `license.json` اتمسح أو اتعدّل، أو الدومين/قاعدة البيانات اتغيّروا | كلّم المالك لمفتاح ترخيص جديد (DEPLOYMENT §٤) |
| النظام كله مش بيفتح وSupabase «Paused» | المشروع المجاني اتوقّف بعد أسبوع من غير استخدام | لوحة Supabase ← المشروع ← Restore. البيانات مابتضيعش |
| الأرقام في الرئيسية مختلفة عن المتوقع | المرتجعات بتتخصم من مبيعات يوم المرتجع، مش يوم البيع | راجع «المحاسبة» ← السجل اليومي |

## للمطوّر: فين أشوف الخطأ الحقيقي
```sql
-- آخر الأخطاء من كل الأجهزة
select context, message, occurrences, last_seen, ua, detail
from pos.omraa_error_log order by last_seen desc limit 50;

-- انقطاعات النت
select started_at, duration_ms, page from pos.net_outages order by started_at desc limit 50;

-- سلامة البيانات
select public.pos_fn_integrity_check();
```
